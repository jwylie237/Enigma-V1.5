This is an Enigma Emulator. More specifically it is an Enigma M4 Emulator. The latest version of Enigma that was in service during WW2. This Emulator is a 1:1 replica in terms of functionality. Using this emulator you can learn how Enigma works and the difficulty the 
Allied powers faced in decyphering the ciphers generated by Enigma.
